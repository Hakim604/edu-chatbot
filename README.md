# 🎓 المساعد التعليمي — Assistant Pédagogique IA

تطبيق ويب يعمل بالذكاء الاصطناعي (Gemini API) لإعداد **ملخصات الدروس** و**جذاذات الدرس** بالعربية والفرنسية.

---

## 🚀 التشغيل السريع

### الطريقة 1 — مباشرة (الأبسط)

> ⚠️ لن تعمل هذه الطريقة مع بعض المتصفحات بسبب قيود CORS على ES Modules.

افتح الملف `index.html` مباشرة في المتصفح.

### الطريقة 2 — خادم محلي بسيط (مُوصى به)

```bash
# تأكد من تثبيت Node.js أولاً
cd C:\Users\hakim\.gemini\antigravity\scratch\edu-chatbot
npx serve .
```

ثم افتح المتصفح على: **http://localhost:3000**

### الطريقة 3 — Python HTTP Server

```bash
cd C:\Users\hakim\.gemini\antigravity\scratch\edu-chatbot
python -m http.server 8080
```

افتح: **http://localhost:8080**

---

## 🔑 إعداد مفتاح API

1. اذهب إلى [Google AI Studio](https://aistudio.google.com)
2. أنشئ مفتاح API مجاناً
3. في التطبيق، اضغط على ⚙️ (الإعدادات)
4. أدخل المفتاح واضغط "حفظ"

> المفتاح مخزّن في متصفحك فقط (localStorage) — لا يُرسَل لأي خادم.
